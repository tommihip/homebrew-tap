# homebrew-tap

Homebrew tap for [Tommi Hippelainen](https://github.com/tommihip)'s tools.

```bash
brew install --cask tommihip/tap/termsie
```

| Cask | What it is |
| --- | --- |
| [`termsie`](Casks/termsie.rb) | A native macOS terminal with floating, colour-coded panes in one window — [termsie.com](https://termsie.com) |

The casks here are generated by each project's release script; edit those rather
than this repository by hand.
